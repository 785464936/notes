# 渐开线标准直齿圆柱齿轮的几何尺寸

|    名称    |        代号        |                                       小齿轮                                        |                          大齿轮                           |
|:----------:|:------------------:|:-----------------------------------------------------------------------------------:|:---------------------------------------------------------:|
|    模数    |        $m$         |                                    $m = p/\pi{}$                                    |                             <                             |
|   压力角   |     $\alpha{}$     |                                  一般$20\degree{}$                                  |                             <                             |
| 分度圆直径 |       $d{}$        |                                 $d_{1} = mz_{1}{}$                                  |                    $d_{2} = mz_{2}{}$                     |
|   齿顶高   | $h_{\mathrm{a}}{}$ |             $h_{\mathrm{a}1} = h_{\mathrm{a}2} = h_{\mathrm{a}}^{*}m{}$             |                             <                             |
|   齿根高   | $h_{\mathrm{f}}{}$ |         $h_{\mathrm{f}1} = h_{\mathrm{f}2} = (h_{\mathrm{a}}^{*}+c^{*})m{}$         |                             <                             |
|   齿全高   |       $h{}$        |                  $h_{1} = h_{2} = (2h_{\mathrm{a}}^{*}+c^{*})m{}$                   |                             <                             |
| 齿顶圆直径 | $d_{\mathrm{a}}{}$ |                 $d_{\mathrm{a}1} = (z_{1}+2h_{\mathrm{a}}^{*})m{}$                  |    $d_{\mathrm{a}2} = (z_{2}+2h_{\mathrm{a}}^{*})m{}$     |
| 齿根圆直径 | $d_{\mathrm{f}}{}$ |              $d_{\mathrm{f}1} = (z_{1}-2h_{\mathrm{a}}^{*}-2c^{*})m{}$              | $d_{\mathrm{f}2} = (z_{2}-2h_{\mathrm{a}}^{*}-2c^{*})m{}$ |
|  基圆直径  | $d_{\mathrm{b}}{}$ |                        $d_{\mathrm{b}1} = d_{1}\cos\alpha{}$                        |           $d_{\mathrm{b}2} = d_{2}\cos\alpha{}$           |
|    齿距    |       $p{}$        |                                    $p = \pi m{}$                                    |                             <                             |
|  基圆齿距  | $p_{\mathrm{b}}{}$ |                          $p_{\mathrm{b}} = p\cos\alpha{}$                           |                             <                             |
|    齿厚    |       $s{}$        |                                   $s = \pi m/2{}$                                   |                             <                             |
|   齿槽宽   |       $e{}$        |                                   $e = \pi m/2{}$                                   |                             <                             |
|    顶隙    |       $c{}$        |                                   $c = c^{*}m{}$                                    |                             <                             |
| 标准中心距 |       $a{}$        |                          $a = \dfrac{m(z_{1}+z_{2})}{2}{}$                          |                             <                             |
|  节圆直径  |   $d^{\prime}{}$   |                          标准中心距时，$d^{\prime} = d{}$                           |                             <                             |
|   传动比   |       $i{}$        | $i = \dfrac{\omega_{1}}{\omega_{2}} = \dfrac{d_{2}}{d_{1}} = \dfrac{z_{2}}{z_{1}}{}$ |                             <                             |
